## Evidence and claims

The report adds partial source/runtime correspondence for five actual dependencies, including VRF service and notifier. That is useful new evidence, qualified as Sourcify partial match plus pinned/current code hashes, not complete independent recompilation. A signed-node keeper repeat passed 28 transactions after an earlier unexplained receipt timeout; the repeat does not explain or erase the failure. Existing full-suite results stay scoped to their unchanged inputs. No real-wallet extension pass or FWA publication acceptance follows.

Creator metric correction: the scenario's creator net is claimed+Balancer.balance+listed backing+FWA.ownerProceeds minus deposited minus nftsWon × 0.2 ETH. It **already deducts a fixed stated-value proxy for each curated NFT won**. Actual acquisition/opportunity value and creator transaction gas remain unmeasured. The owner packet's wording is corrected accordingly; no measured amount changes.

Those are real mismatches requiring follow-up. Delayed jackpot restocking and a deliberately disclosed small working buffer are product tradeoffs, not logical contradictions.
