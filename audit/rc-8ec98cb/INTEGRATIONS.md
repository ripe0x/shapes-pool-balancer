For each address the delegated verifier queried `https://sourcify.dev/server/v2/contract/1/<address>?fields=compilation` and `?fields=sources`. Sourcify reported runtime `match`, rather than `exact_match`, for the six contracts above: the metadata differed, but the deployed code matched Sourcify's verified compilation. The primary FWA factory, StandardPool, StandardPoolBuyback, notifier and Shapes source files returned by Sourcify were byte-identical to the copies in this audit snapshot, checked by SHA-256 of source contents. The FWA implementation runtime code hash exactly matched the Balancer constructor's pinned hash. This supports source-to-runtime correspondence for the reviewed paths without proving every external execution property.

Live factory getters at that block: implementation = `0x85Faf...fEe7`; VRF service/coordinator and notifier as listed; `globalPurchasesEnabled=true`, `globalWithdrawOnly=false`, `vrfRequestsPaused=false`, `vrfSubscriptionActive=true`, `poolCreationEnabled=true`, `edgeBps=500`, `maxAcquisitionsPerTx=5`, `maxStagedListings=0`, `selectionTimeoutBlocks=30`, `maxActivationsPerAcquisition=6`. Shapes reported `mintFee=0.001 ETH`, nine denominations, 0.01 ETH minimum unit; all nine denomination values matched Balancer's table: 0.01, 0.05, 0.1, 0.5, 1, 5, 10, 50 and 100 ETH. Service getters reported requests unpaused, subscription active, gas estimate 1,800,000, margin 3,000 bps and flat fee zero. The service's verified `requestFee()` computes `gasEstimate × tx.gasprice × 1.3 + flat`. Raw `eth_call` with explicit `gasPrice` of 1 and 5 gwei returned **0.00234** and **0.0117 ETH**; default `cast call` returned zero and `cast call --gas-price` did not reproduce those fields. Any fee claim using a default view call lacks a valid gas-price context.

The factory's acquisition cap of five and six staged activations per acquisition are constants in its verified source, not admin-adjustable values. FWA's purchase operator is owner-set; its check is a bounded staticcall returning an exact ABI bool. Inventory lists and owner proceeds withdrawals require FWA pool ownership; active inventory exits lock during unresolved draws, and player refund withdrawal requires the purchaser. Atomic NFT delivery gets 150,000 gas; purchase notification gets 300,000 gas. Those limits constrained the hostile-callback gas hypotheses in this audit. The service authenticates the Chainlink coordinator for word delivery. If any of these enforcement paths were absent, the Balancer has no independent replacement check for overselling, prize/refund control or proceeds ownership. The fork tests exercised selected checks; source correspondence and live getters alone do not prove every branch.

**Draw Packs:** `script/Deploy.s.sol` creates a new Packs instance from local `lib/shape-packs` with minimum pack units 2. There was no project Packs deployment on mainnet to compare. The Balancer constructor checks `packs.shapes()` and `MIN_PACK_VALUE()` but does not pin a Packs code hash or independently assert redemption equals nominal value. Fork Packs tests exercise this locally deployed source; deployed runtime verification remains impossible before a project deployment.
